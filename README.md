# Blahaj-Pad
Blahaj-Pad is a 3-key macropad for users who need extra space on their keyboard or who simply want to set up their own keyboard values. This repo provides the firmware, CAD files, and gbr files for anyone who wants to recreate this project.

## Tools, Manufactures, Languages Used
- Onshape CAD
- KiCAD
- Python
- OSHPark
